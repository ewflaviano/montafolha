# Segurança

Se encontrar uma falha que possa expor imagens, PDFs, dados de navegação ou credenciais, envie um relato para [ewanderson.flaviano@gmail.com](mailto:ewanderson.flaviano@gmail.com). Não publique detalhes exploráveis em uma issue.

Descreva passos de reprodução com dados sintéticos, impacto e versões afetadas. Não envie imagens pessoais nem tokens. O mantenedor revisará o relato antes de uma divulgação pública.
